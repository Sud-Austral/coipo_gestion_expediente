# Gestión de Expedientes — Maqueta MVP

Maqueta funcional para validación del **FW Coipo — Etapa 3: Diseño**.

## Versión actual

**v0.2.0 — En revisión**

Esta versión incorpora las decisiones acordadas durante la revisión de pantallas 1 a 7.

## Ejecutar

```bash
npm install
npm run dev
```

También se puede usar `ejecutar.bat` en Windows.

## Perfiles de prueba

El selector superior permite cambiar entre:

- Jefatura
- Responsable

## Pantallas

### Jefatura

- Dashboard
- Bandeja
- Nueva solicitud

### Responsable

## Alcance

La maqueta usa datos ficticios y estado en memoria. No incorpora backend, base de datos ni almacenamiento documental.

## Control de versiones

Revisar `VERSIONES.md`. La versión solo se considera base válida cuando el usuario entrega explícitamente su **OK**.
